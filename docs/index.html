Educational Disclaimer:

This game is meant to increase awareness of various contraceptives. Although properly combining some contraceptives can increase effectiveness, the combinations represented in this game are not meant to serve as reccomendations. The percentages displayed on the graphics are failure rates. This means a higher percentage indicates a less effective contraceptive. The ranking of tiles in this game reflects these percentages, but effectiveness is not the only factor when choosing contraceptives. For more information on contraceptives, their effectiveness, and to learn what might work best for you visit https://www.cdc.gov/contraception/about/index.html.
